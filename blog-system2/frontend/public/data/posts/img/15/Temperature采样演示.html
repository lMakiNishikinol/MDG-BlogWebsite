从 logit 到概率

更保守 更随机
T=1.0
候选过滤
top_k 4
top_p 0.90

模型先给每个候选 token 一个原始分数 logit，temperature 会在 softmax 前缩放这些分数。 p i = softmax ( z T ) i 其中 z 表示所有候选 token 的 logit 向量；T 是 temperature；i 表示取第 i 个候选 token 的概率。过滤后会把保留下来的概率重新归一化，得到最终采样概率。

token z i z i T p i = softmax ( z T ) i p i p top 保留 q i
读表方式：p_i 是 temperature 后的完整概率；top_k/top_p 先决定哪些 token 被保留，再把保留项重新归一化成最终采样概率 q_i。

采样概率

T < 1 概率更集中，输出更稳定。
T = 1 保持模型原始分布。
T > 1 概率更分散，输出更多样。
完整概率 p_i 最终采样概率 q_i

按最终概率采样

点击“采样一次”，按最终概率随机抽取一个 token。
注意：采样不是永远选择概率最高的 token，而是按最终概率 q_i 抽签。被 top_k/top_p 过滤掉的 token 概率会变成 0。
