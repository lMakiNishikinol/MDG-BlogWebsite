# 制作一个文件助手 Agent

## 一、任务概览

本次作业要求大家使用 Python 和 OpenAI Agents SDK，制作一个简单的 Agent。

这个 Agent 需要能够：

1. 理解用户的自然语言任务；
2. 判断是否需要调用工具；
3. 调用工具完成具体操作；
4. 根据工具返回结果继续处理任务；
5. 输出最终结果；
6. 展示工具调用过程。

本作业建议使用 OpenAI Agents SDK。

## 二、前置知识

下面这些内容是制作 Agent 前可能会用到的前置知识。

建议边做边查，能把 Agent 跑起来、看懂大致执行过程即可。

### 1. Agent 基本概念

1. Agent 和网页中的普通对话有什么区别？
2. 为什么 Agent 可以完成“读取文件、写入文件”这类操作，而普通聊天模型通常不能直接做到？

### 2. System Prompt

1. 系统提示词是什么？
2. 系统提示词和用户输入有什么区别？

### 3. Tool

1. 模型如何知道 Tool 的存在以及使用方式？
2. 模型是怎么调用 Tool 的？

### 4. Agent Loop

1. Agent 完成“读取文件、总结内容、写入文件”时，大概会经历哪些步骤？

### 5. MCP

1. MCP 是什么？
2. MCP 有什么用？

### 6. Skill

1. Skill 和 Tool 有什么区别？

## 三、作业要求

本次作业需要完成以下内容：

1. 使用 OpenAI Agents SDK 搭建文件助手 Agent。
2. 为 Agent 编写 system prompt。
3. 实现并接入本地工具。
4. 让 Agent 能够根据用户任务调用工具。
5. 展示工具调用日志。
6. 保留一次运行记录。

### 1. 内置工具

需要实现：

- 时间工具：返回当前日期和时间。
- 文件读取工具：读取指定文本文件内容。
- 文件写入工具：将内容写入指定文本文件。

也可以额外实现：

- 文件列表工具：列出指定目录中的文件。
- 文件追加工具：向指定文本文件追加内容。

### 2. 工具调用日志

程序需要展示 Agent 的工具调用过程。

运行时请保留工具调用过程，方便回顾 Agent 的执行步骤。

## 四、可选扩展

有兴趣的同学可以尝试

### 1. MCP

不需要从零实现 MCP 协议，也不需要自己写完整 MCP server。

可完成：

1. 接入任意公开的MCP
2. 在 OpenAI Agents SDK 项目中连接 MCP server；
3. 让 Agent 调用 MCP 工具；
4. 在日志中展示 MCP 工具调用过程。

### 2. Skill

用 Markdown 文件描述某类任务的处理流程，让 Agent 在执行任务时参考。

可选择的方向：

1. 总结文件；
2. 写学习日志。
